# Brand source art

Master exports for the My Ad, LLC marks.

The app serves the downscaled `@2x` derivatives in `frontend/brand/`:

| File | Size | Rendered at |
|---|---|---|
| `my-ad-llc@2x.png` | 440×354 | 220×177 (login card) |
| `my-ad-mark@2x.png` | 80×69 | 40×35 (header) |

Regenerate those from these masters if the brand art changes. Keeping the
masters here keeps them out of the served frontend directory.
