    Gmail inbox feed

    Connect the TD Gmail so CourtOps can pull new parent/player mail into the review inbox. Credentials stay on this server (the app password is encrypted). Get latest only fetches messages newer than the stored IMAP UID cursor.

    How to enable the Gmail feed

    Gmail will not accept the account’s normal password over IMAP. Use a Google App Password (2-Step Verification required). CourtOps talks to imap.gmail.com read-only and never sends or deletes mail.

    1. Sign in to the TD Gmail in a browser (the mailbox that receives USTA / parent mail, or a dedicated inbox that those messages are forwarded to).
    2. Open Google Account → Security.
    3. Turn on 2-Step Verification if it is off. App Passwords only appear after that.
    4. Open App passwords. If Google hides the page, search the account for “App passwords”.
    5. Create an app password: app = Mail, device = Other (CourtOps). Google shows a 16-character password once.
    6. Copy that password into App password above (spaces are fine). Save settings. The password is encrypted at rest and is never shown again.
    7. Optional: set a Gmail search so the feed only pulls tournament mail, e.g. from:playtennis.usta.com or newer_than:14d (Gmail search operators).
    8. Optional: pick File under tournament. If you leave it blank, CourtOps routes by the message To: against Setup → Tournaments → Ingest address.
    9. Click Get latest. New messages land in Inbox with source gmail. The UID cursor advances so the next fetch only asks for newer mail. First run uses the lookback window (default 7 days, at most 50 messages).

    Workspace / school Google accounts: the admin may have to allow IMAP and App Passwords (or “Less secure apps” is not enough — use an App Password). If login fails with “Application-specific password required”, the field is still the account’s normal Gmail password instead of the 16-character App Password.

    Forwarding: you can keep using a personal Gmail and auto-forward USTA mail into the TD inbox, then connect that inbox here. Poll minutes are stored for a future background worker; until then, use Get latest (or refresh this page and fetch after mail arrives).

    Outlook / Microsoft inbox feed

    Connect the TD Microsoft 365 mailbox so CourtOps can pull new parent/player mail into the review inbox via Microsoft Graph (app-only). Credentials stay on this server (the client secret is encrypted). Get latest only fetches messages newer than the stored received-time cursor. This is not interactive Microsoft login.

    How to enable the Outlook / Microsoft feed

    CourtOps reads mail with Microsoft Graph application permissions (OAuth 2.0 client credentials, scope https://graph.microsoft.com/.default). There is no interactive Microsoft sign-in. The app must have admin-consented Mail.Read (not Mail.ReadWrite). CourtOps calls GET /v1.0/users/{mailbox}/messages (not /me) and never sends or deletes mail.

    1. In the Entra admin center, open the app registration that should read the TD mailbox. Copy Directory (tenant) ID and Application (client) ID (the GUID, or api://{guid} — token calls use the GUID).
    2. Under Certificates & secrets, create a client secret if the current one is expired. Copy the secret Value once (it is not shown again in Entra).
    3. Under API permissions, add Microsoft Graph Application permission Mail.Read (not a delegated permission). Click Grant admin consent for the tenant.
    4. Mailbox is the user principal to read, e.g. TD@myadllc.com. Graph app-only mail is /users/{mailbox}/messages, not the signed-in /me mailbox.
    5. Paste tenant ID, client ID, mailbox, and client secret above. Enable the feed. Save settings. The secret is encrypted at rest and is never shown again.
    6. Optional: set a Mail search so Graph $search narrows to tournament mail. Optional: pick File under tournament. If you leave it blank, CourtOps routes by the message To: against Setup → Tournaments → Ingest address.
    7. Click Get latest. New messages land in Inbox with source outlook. The received-time cursor advances so the next fetch only asks for newer mail. First run uses the lookback window (default 7 days, at most 50 messages).

    Admin consent: without tenant admin consent for application Mail.Read, Get latest returns 403 even with a valid secret. Personal outlook.com / Hotmail without this Entra app is not supported.

    Poll minutes are stored for a future background worker; until then, use Get latest (or refresh this page and fetch after mail arrives).
